# 内容复盘轻量模板

只为被 PDCA 或人工标记为值得复盘的内容填写。它不是 KPI 周报，也不要求每次都有完整答案。

1. **表现事实**：来自 OPC-ERP 的阅读、播放、推荐、互动或增长信号是什么？
2. **当时判断**：选题、角度、标题、结构、平台或时机中，哪个判断可能起作用？
3. **适用条件**：这个判断在什么内容、受众、平台或时效条件下才成立？
4. **下次动作**：要继续、停止、改写，还是只保留为待验证假设？
5. **方法候选（可选）**：若已重复出现且证据足够，提炼一条可写入指定 SKILL 的规则。

人填写自己的实际判断；Codex 可以补充证据、反例和归纳，但不能把未经确认的推测写成正式规则。
