## 七、2026-10-03 补记：彻底取消"过期" + 类别口径修正

周老师 10-03 反馈两处：① 类别聚焦数字看着太少；② 还显示"已过期"。

### 7.1 根因
- **类别聚焦数少**：该板块按"当前选中日期"统计，默认落在最新一天（10-02 仅 24 条），拆 7 类就是 2/4/6/4/6/1/1。而顶部统计卡是**全库**口径 —— 两块口径不一致造成误读。
- **还有"已过期"**：10-02 只删了"首页渲染时的自动过期"，**没清存量、也没拆机制**。仍有 1381 条历史 `status='expired'`；且 `scheduler.py` 里**每天凌晨 3 点的自动过期定时任务仍在注册**（会持续产生新的过期）。

### 7.2 改动
1. **数据**：1381 条 `expired` → `scored`（过期前状态，全部有评分），现 expired = 0。
2. **机制**（断根）：
   - `app/services/scheduler.py`：删除 `expire_old_topics()` 函数与其 3 点定时任务（随之清理 `datetime`/`timedelta`/`json`/`get_db`/`get_int_setting` 无用导入）。
   - `app/routers/topics.py`：删除 `POST /api/topics/auto-expire` 接口。
3. **界面**：
   - `dashboard.html`：撤掉"已过期"统计卡（6 格 → 5 格）、状态筛选里的"🪦 已过期"标签、列表头"· 已过期 N 条"、卡片上的"挖坟"按钮、空状态里的过期文案；搜索框占位去掉"（含已过期）"。
   - `topic_detail.html` / `base.html`：撤掉过期徽标与 `expired` 标签映射。
4. **类别口径**：`main.py` 为每个类别新增 `lib_total`（全库总数）。卡片改为 **大字=全库总数**、小字="本日/当前 N · 最高 X"，两种口径同时可见。

### 7.3 验证
- 首页：无"已过期"字样、无 `1381`；统计卡 = 1586 / 111 / 1448 / 27 / 0。
- 类别卡：全库 306·134·222·329·233·174·188（与库一致），本日 2/4/6/4/6/1/1。
- 调度器 `jobs` 由 2 → **1**（仅剩反馈同步），过期任务已拆。
- `POST /api/topics/auto-expire` 已不可用（405）。
