# 变更记录 · 归类三级树（2026-10-03）

## 背景（周老师定调）

> "默认不跨分类，你说的失控就是对应了安全，不管是大模型失控还是智能体失控都是安全，
> 优先根据动词、动名词做分类和事件归并。但是用户可以手动增加事件归并。
> 三级树做左侧菜单，替代现在的事件归并。event_key 留着。"

即：**分类的主导权从"谁的事"（名词）转到"发生了什么事"（动词）**，并把它和事件归并合成一套结构。

## 一、分类改成动词优先（`app/verbs.py`，新建）

优先级链（高 → 低，命中即定）：

**政策与监管 > AI 安全与风险 > 行业与商业 > Agent 与智能体 > 大模型与技术 > AI 工具与应用**

- 政策排最前：标题主语是动作发出者 —— "FTC 调查 OpenAI 的安全实践"主线是监管动作，归政策；
  "OpenAI 智能体失控"没有监管动词，仍落安全。
- 安全链收的是**事故性动作**：失控 / 越狱 / 入侵 / 渗透 / 突破沙箱 / 泄露 / 诈骗 / 叫停 / 暂停训练 / 对齐失败……
- 动词与领域词全不命中才退回 `taxonomy.classify()` 的名词兜底，最后一档「其他」。
- 修改记录：第一版把安全排最前，试算发现"监管动作"被安全吞掉（政策→安全 33 条），调序后降到 17 条。

**实测效果**：全库 1591 条中 **500 条分类变化**；「其他」从 190 降到 **67**。
`evt-1461`（OpenAI 智能体失控，6 条）从横跨 4 类 → **全部归入 AI 安全与风险**。

## 二、地域 + 主体（`app/geo.py`，新建）

- 二级 `region`：中国 / 美国 / 其他（三档，不新造国家清单）。
- 三级 `entity`：政府机构 或 具体公司。**政府机构优先**（"FTC 调查 OpenAI" → 主体 FTC、地域美国）。
- 近 14 天实测：美国 65% / 其他 25% / 中国 8%；主体未识别 30%（多为研究、趋势、观点类，本就没有单一主体）。
- 词典由 AI 代维护（`COMPANY_REGION` / `GOV_REGION`）。

## 三、数据迁移（`scripts/init_db.py`）

加 `topics.region` / `topics.entity` 两列；一次性回填 1591 条；
分类按动词重判；**事件线整线统一分类**（整线标题拼起来再判一次），实现"默认不跨分类"。

- 用 `system_settings.tree_v1_migrated` 打标记：**只跑一次**，不覆盖日后人工修正。
- 逐条写审计：`category_reclassified` 500 条、`event_category_unified` 35 条。
- 幂等实测：复跑两次事件数不增。

**结果**：跨分类事件线 **0**（迁移前 4 条）。

## 四、三级树页面（`app/routers/tree.py` + `app/templates/tree.html`，新建）

- 左侧菜单「归类」→ `/tree`，**替代原「事件归并」入口**（`/events` 路由保留，用于候选组与 Agent 手册）。
- 三层逐级展开：分类 → 地域 → 主体 → 格子。
- 格子内素材**按 `event_key` 聚成事件线**，未归并的列在「散素材」。
- **手动归并**：勾选 ≥2 条 → 「归为同一件事」；每条线右侧「拆线」。人不用等 Agent。
- 周期切换：近7日 / 近30日 / 本季度 / 本年 / 历史全部。

## 五、验收
