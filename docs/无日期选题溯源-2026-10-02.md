## 二、根因：接口缺字段（这是"为什么没有日期"的真正答案）

`app/routers/topics.py` 第 18-24 行，创建选题的接口模型只声明了 6 个字段：

```python
class TopicCreate(BaseModel):
    title: str
    summary: str = ""
    raw_content: str = ""
    source_type: str = "manual"
    source_ref: str = ""
    tags: list = []
```

**没有 `news_date`、没有 `source_name`、没有 `source_level`、没有 `original_url`、没有 `published_date`。**

Pydantic 默认**丢弃未声明的字段**，且不报错。所以：

| 谁从这条路进来 | 结果 |
|---|---|
| `add_trending_topics.py`（传了完整日期/来源/URL） | **全被扔掉** → 20 条无日期 |
| 8-13 那批（同样方式） | **全被扔掉** → 13 条无日期 |
| `/manual` 手动录入页 | **同样扔掉** |
| **OpenClaw**（走的是另一条路径，文件名带日期） | **一条不缺** ✅ |

**所以这不是"解析器只认一种格式"，是"创建接口本身缺 5 个字段"。** 你以后每换一个导入方式，就再丢一批——**这是同一个坑，不是新坑。**
